# آخر وظيفة — الموقع التعريفي

صفحة تعريفية مستقلة لرواية «آخر وظيفة»، بهوية «أرشيف السيادة»: ملف صيانة مدني، مخطط خدمات مترو، وغلاف أدبي عربي معاصر.

## التشغيل محليًا

المتطلبات: Node.js 24 أو أحدث.

```bash
npm install
npm run dev
```

فحص النسخة النهائية:

```bash
npm run check
npm run preview
```

## النشر على GitHub Pages

الموقع يُنشر تلقائيًا من فرع `main` عبر GitHub Actions. سير النشر موجود في `.github/workflows/pages.yml` ويشغّل تثبيتًا نظيفًا، وفحص الكود، وبناء نسخة الإنتاج، ثم ينشرها على GitHub Pages.

يمكن أيضًا تشغيل النشر يدويًا من تبويب `Actions` عبر `workflow_dispatch`.

## البنية

- `src/App.tsx`: المحتوى والتكوين السردي للصفحة.
- `src/styles.css`: الهوية البصرية والخطوط والألوان والاستجابة.
- `src/components`: الحركة المقيدة، مسار السلطة، وأدوات المشاركة.
- `public/images`: الصورة الرئيسية ونسخها المحسنة والمشاركة الاجتماعية.
- `.github/workflows/pages.yml`: الفحص والبناء والنشر التلقائي.
- `VISUAL_IDENTITY.md`: قواعد الهوية البصرية والنص المستخدم لإنشاء الصورة الأصلية.
- `CONTENT_GUIDE.md`: صوت الصفحة، والمصطلحات العامة، وحدود الكشف.

## مبادئ التنفيذ

- صفحة واحدة بلا Router لتفادي أخطاء المسارات في GitHub Pages.
- اتجاه RTL ولغة عربية كاملة، مع خطوط عربية محلية بلا اتصال بخدمة خطوط خارجية.
- صور AVIF وWebP، وأبعاد ثابتة لتقليل تغيّر التخطيط.
- دعم لوحة المفاتيح، رابط تجاوز للمحتوى، حالات تركيز واضحة، واحترام `prefers-reduced-motion`.
- لا تحليلات ولا متتبعات ولا ملفات تعريف ارتباط.
